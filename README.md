# My-web-guide
 Simple example-based guide for creating a website.
 It is a collection of all the information I found useful,
  written in a way that's easy for me to find again,
  summarized so it gets to the point quickly.
 It wouldn't have been possible to make without the [documentation pages and tutorials of MDN](https://developer.mozilla.org/en-US/docs/Learn_web_development),
  as much of the information in this guide is directly copied from there.

## Who is this for?
 Me, and anybody who finds it useful.
