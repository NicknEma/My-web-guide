General

Reduce name collisions (in your scripts)

All the scripts in a page share the same global namespace. If a page loads many scripts, and each script declares global names, it's possible that you'll have name collisions.

<script>
	const h = document.querySelector("header");
	/* ... */
</script>
<script>
	const h = document.querySelector("h1");
	/* ... */
</script>
Uncaught SyntaxError: Identifier 'h' has already been declared

A common practice is to wrap the entire script into an anonymous function, and call it immediately.

<script>
	( () => {
		const h = document.querySelector("header");
		/* ... */
	} )(); /* ← Note the parentheses: we aren't just defining it, we're also calling it */
</script>
<script>
	( () => {
		const h = document.querySelector("h1");
		/* ... */
	} )(); /* ← Same here */
</script>

For example, this very page contains many scripts all manipulating a different canvas element. To avoid having to find a unique name for every canvas constant, each script is wrapped in an anonymous function.

(I found out about this trick by reading this example.)

DOM manipulation

Get an element with an Id

To get a reference to an element knowing its Id, use the getElementById() method of document.

<div id="my_div"> <div id="my_other_div">
const my_div = docoment.getElementById("my_div");

Get an element's parent

To get the parent element of an element, use its parentElement property. To get the parent node of an element (which may or may not be an element), use its parentNode property. An Element inherits both properties from Node.

const element = /* ... */;

const parent_element = element.parentElement;
const parent_node    = element.parentNode;

Get an element's closest ancestor matching a selector

To get an element's closest ancestor matching a selector, use its closest() method.

<body>
	<section class="container">
		<p>This is a
			<span id="my_span">paragraph</span>
		with text.</p>
	</section>
<body>
const my_span = document.getElementById("my_span");
const element_of_class_container = my_span.closest(".container");

Get an element's children and grandchildren

To get a list of an element's children and grandchildren (and so on, recursively), use the getElementsByTagName() method.

/* Get all the children and grandchildren of my_elem, as a live collection */
const children = my_elem.getElementsByTagName("*")

This is the syntax of the getElementsByTagName() method.

getElementsByTagName(tagName)

To get a static (not live) list, use the querySelectorAll() method with the same argument.

/* Get all the children and grandchildren of my_elem, as a static collection */
const children = my_elem.querySelectorAll("*")

Note: It is probabily faster to use getElementsByTagName() than querySelectorAll(), so use the former if it makes no difference.

Get the current script element

To get the script element of the script that is currently being processed, use the currentScript property of document.

Check if an element matches a selector

To check if an element would be selected by a selector, call its matches() method.

const selector = "div.example"; /* ← Could be any valid selector */
const element  = document.querySelector(selector);

console.log(element.matches(selector)); /* true */

This can be used to check wether an element has a particular child or a particular sibling.

<div>
	<canvas width="500" height="100">An empty canvas.</canvas>
	<script>
	( () => {
		const parent = document.currentScript.parentElement;
		for (const child of parent.children) {
			if (child.matches("canvas")) {
				console.log(`This script has a canvas sibling: ${child.tagName}\n`);
			}
		}
	} )();
	</script>
</div>
An empty canvas.

User input

Listen to mouse movement

To listen to mouse movement events, add an event handler to the mousemove event.

/* Do this: */
document.onmousemove = (event) => { /* Process event */ }
/* or this: */
document.addEventListener("mousemove", (e) => { /* Process event */ });

The mousemove event is a kind of MouseEvent. This means it has properties like screenX/Y, clientX/Y, pageX/Y and movementX/Y. See MouseEvent for a full list.

Listen to mouse button presses

To listen to mouse button press events, add an event handler to the mousedown event.

/* Do this: */
document.onmousedown = (event) => { /* Process event */ }
/* or this: */
document.addEventListener("mousedown", (e) => { /* Process event */ });

The mousedown event is another kind of MouseEvent (see "Listen to mouse movement").

Listen to mouse button releases

To listen to mouse button release events, add an event handler to the mouseup event.

/* Do this: */
document.onmouseup = (event) => { /* Process event */ }
/* or this: */
document.addEventListener("mouseup", (e) => { /* Process event */ });

The mouseup event is another kind of MouseEvent (see "Listen to mouse movement").

Listen to mouse clicks

To listen to mouse click events, add an event handler to the click event.

/* Do this: */
document.onclick = (event) => { /* Process event */ }
/* or this: */
document.addEventListener("click", (e) => { /* Process event */ });

The click event is another kind of MouseEvent (see "Listen to mouse movement").

Listen to mouse double-clicks

To listen to mouse double-click events, add an event handler to the dblclick event.

/* Do this: */
document.ondblclick = (event) => { /* Process event */ }
/* or this: */
document.addEventListener("dblclick", (e) => { /* Process event */ });

The dblclick event is another kind of MouseEvent (see "Listen to mouse movement").

Listen to key presses

To listen to key press events, add an event handler to the keydown event.

/* Do this: */
document.onmousemove = (event) => { /* Process event */ }
/* or this: */
document.addEventListener("mousemove", (e) => { /* Process event */ });

The keydown event is a kind of KeyboardEvent. This means it has properties like key, ctrlKey, shiftKey and repeat. See KeyboardEvent for a full list.

The event target of a key event is the currently focused element which is processing the keyboard activity. The event bubbles. In the following example, both the div and input elements receive the event.

<div id="container">
	<input id="input"/>
</div>
<pre id="output"></pre>
const output = document.querySelector("#output");
function handle_keypress(e) {
	output.textContent += `${e.currentTarget.tagName}: ${e.key}\n`;
}

document.querySelector("#container").addEventListener("keydown", handle_keypress); /* Add handler to the <div> element */
document.querySelector("#input").addEventListener("keydown", handle_keypress);     /* Add handler to the <input> */

Clipboard

	
	
Listen to clipboard copies

	
To do something when the user copies data to the clipboard, add an event handler to the copy event.

	

	
/* Do this: */
document.oncopy = (event) => { /* Process event */ }
/* or this: */
document.addEventListener("copy", (e) => { /* Process event */ });

	

	
The copy event is a kind of ClipboardEvent.
	This means it has the clipboardData property.

	
Note: there are also events for cutting and pasting.

	
	
	
	
	
	
Graphics

	
	
	
	
Clear the canvas

	
To clear the canvas or a portion of it, call the clearRect() method on the context.

	
	

	
<canvas width="500" height="100"/>

	
const canvas = document.querySelector("canvas");
const ctx = canvas.getContext("2d");

ctx.clearRect(0, 0, canvas.width, canvas.height)

	Empty canvas.
	
	

	
	
This is the syntax of the clearRect() method:

	

	
clearRect(x, y, width, height)

	

	
	
	
	
Draw a rectangle

	
To draw a rectangle, place a canvas element and use the canvas API.

	
	
After you've acquired a 2d canvas context, follow these steps:
	
    
		
  1. Begin a new path by calling beginPath().
    2. 
		
  2. Define a rectangular path with rect().
    3. 
		
  3. (Optional) Set either the fillStyle or the strokeStyle of the context, depending on wether you plan to call fill or stroke.
		If you skip this step, the previously set style will be used (the default if none was set).
    4. 
		
  4. If you want a filled rectangle, call fill();
		if you want the outline, call stroke().
    5. 
		
  5. (Optional) Close the path to bring the pen position to where it was when the path started by calling closePath().
		In the case of drawing a single rectangle, the path will already be closed after the call to rect().
    6. 
	

	

	
	

	
<canvas width="500" height="90"/>

	
const canvas = document.querySelector("canvas");
const ctx = canvas.getContext("2d");

/* Example 1: filled red square */
ctx.beginPath();
ctx.rect(80, 20, 50, 50);
ctx.fillStyle = "red";       /* ← Setting fillStyle, in preparation for fill() */
ctx.fill();
ctx.closePath();             /* ← Explicitly closing the path */

/* Example 2: purple rectangle outline */
ctx.beginPath();
ctx.rect(210, 20, 70, 50);
ctx.strokeStyle = "#3a28d2"; /* ← Setting strokeStyle, in preparation for stroke() */
ctx.stroke();
                             /* ← Not closing the path */

/* Example 2: rectangle using previous color */
ctx.beginPath();
ctx.rect(360, 30, 60, 30);
ctx.fill();                  /* ← Not setting fillStyle nor strokeStyle,
                                  using the previous one */

	Canvas containing three rectangles of different sizes and colors.
	
	

	
	
This is the syntax of the rect() method:

	

	
rect(x, y, width, height)

	

	
	
	
	
Draw a circle

	
	
To draw a circle, place a canvas element and use the canvas API.

	
	
The steps required to draw a circle are the same required to draw a rectangle;
	you only need to change the rect() call with a arc() call.

	
	

	
<canvas width="500" height="100"></canvas>

	
const canvas = document.querySelector("canvas");
const ctx = canvas.getContext("2d");

ctx.beginPath();
ctx.arc(100, 50, 30, 0, Math.PI * 2);
ctx.fillStyle = "#ee8410";
ctx.fill();
ctx.closePath();

	Canvas containing a single orange circle.
	
	

	
	
This is the syntax of the arc() method:

	

	
arc(x, y, radius, startAngle, endAngle)
arc(x, y, radius, startAngle, endAngle, counterclockwise)

	

	
	
	
	
Draw at a fixed framerate

	
To draw at a fixed framerate, define a drawing function and pass it to the setInterval() function.

	
	

	
const canvas = document.querySelector("canvas");
const ctx = canvas.getContext("2d");
/* Rest of initialization code... */

function draw_and_update() {
	ctx.clearRect(/* ... */);
	/* Rest of the drawing/update code... */
}

const delay_milliseconds = 10;
setInterval(draw_and_update, delay_milliseconds);

	Canvas containing a DVD logo. The logo can be made to move and bounce around by clicking some buttons.
	
	
	
	
	

	
	
This is the syntax of the setInterval() function:

	

	
setInterval(func) -> Number
setInterval(func, delay) -> Number
setInterval(func, delay, param1) -> Number
setInterval(func, delay, param1, param2) -> Number
setInterval(func, delay, param1, param2, /* …, */ paramN) -> Number

	

	
	
The function returns a number which uniquely identifies the timer created by the call.
	This identifier can be passed to clearInterval() to stop the repetition.

	
	
This is the syntax of the clearInterval() function:

	

	
clearInterval(intervalID)

	

	
	
Note: setInterval() has nothing to do with the canvas specifically, and can be used to repeatedly call any piece of code.
	Also see setTimeout().
