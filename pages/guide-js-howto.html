User input

Listen to mouse movement

To listen to mouse movement events, add an event handler to the event "mousemove".

/* Do this: */
document.onmousemove = (event) => { /* Process event */ }
/* or this: */
document.addEventListener("mousemove", (e) => { /* Process event */ });

The mousemove event is a kind of MouseEvent. This means it has properties like screenX/Y, clientX/Y, pageX/Y and movementX/Y. See MouseEvent for a full list.

The mousedown event is another kind of MouseEvent (see "Listen to mouse movement").

Listen to key presses

To listen to key press events, add an event handler to the keydown event.

/* Do this: */
document.onmousemove = (event) => { /* Process event */ }
/* or this: */
document.addEventListener("mousemove", (e) => { /* Process event */ });

The keydown event is a kind of KeyboardEvent. This means it has properties like key, ctrlKey, shiftKey and repeat. See KeyboardEvent for a full list.

The event target of a key event is the currently focused element which is processing the keyboard activity. The event bubbles. In the following example, both the div and input elements receive the event.

<div id="container">
	<input id="input"/>
</div>
<pre id="output"></pre>
const output = document.querySelector("#output");
function handle_keypress(e) {
	output.textContent += `${e.currentTarget.tagName}: ${e.key}\n`;
}

document.querySelector("#container").addEventListener("keydown", handle_keypress); /* Add handler to the <div> element */
document.querySelector("#input").addEventListener("keydown", handle_keypress);     /* Add handler to the <input> */

Clipboard

	
	
Listen to clipboard copies

	
To do something when the user copies data to the clipboard, add an event handler to the copy event.

	

	
/* Do this: */
document.oncopy = (event) => { /* Process event */ }
/* or this: */
document.addEventListener("copy", (e) => { /* Process event */ });

	

	
The copy event is a kind of ClipboardEvent.
	This means it has the clipboardData property.

	
Note: there are also events for cutting and pasting.

	
		
	
	
Graphics

	
	
Draw a rectangle

	
To draw a rectangle, place a canvas element and use the canvas API.

	
	
After you've acquired a 2d canvas context, follow these steps:
	
    
		
  1. Begin a new path by calling beginPath.
    2. 
		
  2. Define a rectangular path with rect.
    3. 
		
  3. (Optional) Set either the fillStyle or the strokeStyle of the context, depending on wether you plan to call fill or stroke.
		If you skip this step, the previously set style will be used (the default if none was set).
    4. 
		
  4. If you want a filled rectangle, call fill; if you want the outline, call stroke.
    5. 
		
  5. (Optional) Close the path to bring the pen position to where it was when the path started.
		In the case of drawing a single rectangle, the path will already be closed after the call to rect.
    6. 
	

	

	
	

	
<canvas width="500" height="100"/>

	
const canvas = document.querySelector("canvas");
const ctx = canvas.getContext("2d");

/* Example 1: filled red square */
ctx.beginPath();
ctx.rect(80, 20, 50, 50);
ctx.fillStyle = "red";       /* ← Setting fillStyle, in preparation for fill() */
ctx.fill();
ctx.closePath();             /* ← Explicitly closing the path */

/* Example 2: purple rectangle outline */
ctx.beginPath();
ctx.rect(180, 20, 70, 50);
ctx.strokeStyle = "#3a28d2"; /* ← Setting strokeStyle, in preparation for stroke() */
ctx.stroke();
                             /* ← Not closing the path */

/* Example 2: rectangle using previous color */
ctx.beginPath();
ctx.rect(300, 30, 60, 30);
ctx.fill();                  /* ← Not setting fillStyle nor strokeStyle, using the previous one */

	
	
	

	
	
Draw a circle

	
	
To draw a circle, place a canvas element and use the canvas API.

	
	
The steps required to draw a circle are the same required to draw a rectangle;
	you only need to change the rect call with a arc call.

	
	

	
<canvas width="500" height="100"/>

	
const canvas = document.querySelector("canvas");
const ctx = canvas.getContext("2d");

ctx.beginPath();
ctx.arc(100, 50, 30, 0, Math.PI * 2, false);
ctx.fillStyle = "#ee8410";
ctx.fill();
ctx.closePath();

	
	
	

	
	
This is the syntax of the arc method:

	

	
arc(x, y, radius, startAngle, endAngle);
arc(x, y, radius, startAngle, endAngle, counterclockwise);
