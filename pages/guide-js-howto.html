    User input

    Listen to mouse movement

    To listen to mouse movement events, add an event handler to the event "mousemove".

    /* Do this: */
document.onmousemove = (event) => { /* Process event */ }
/* or this: */
document.addEventListener("mousemove", (e) => { /* Process event */ });

    The mousemove event is a kind of MouseEvent. This means it has properties like screenX/Y, clientX/Y, pageX/Y and movementX/Y. See MouseEvent for a full list.

    Listen to mouse button presses

    To listen to mouse button press events, add an event handler to the mousedown event.

    /* Do this: */
document.onmousedown = (event) => { /* Process event */ }
/* or this: */
document.addEventListener("mousedown", (e) => { /* Process event */ });

    The mousedown event is another kind of MouseEvent (see "Listen to mouse movement").

    Listen to mouse button releases

    Listen to key presses

    To listen to key press events, add an event handler to the keydown event.

    /* Do this: */
document.onmousemove = (event) => { /* Process event */ }
/* or this: */
document.addEventListener("mousemove", (e) => { /* Process event */ });

    The keydown event is a kind of KeyboardEvent. This means it has properties like key, ctrlKey, shiftKey and repeat. See KeyboardEvent for a full list.

    The event target of a key event is the currently focused element which is processing the keyboard activity. The event bubbles. In the following example, both the div and input elements receive the event.

    <div id="container">
	<input id="input"/>
</div>
<pre id="output"></pre>
    const output = document.querySelector("#output");
function handle_keypress(e) {
	output.textContent += `${e.currentTarget.tagName}: ${e.key}\n`;
}

document.querySelector("#container").addEventListener("keydown", handle_keypress); /* Add handler to the <div> element */
document.querySelector("#input").addEventListener("keydown", handle_keypress);     /* Add handler to the <input> */

    Clipboard
    
	
	
    Listen to clipboard copies
    
	
    To do something when the user copies data to the clipboard, add an event handler to the copy event.
    
	
    
	
    /* Do this: */
document.oncopy = (event) => { /* Process event */ }
/* or this: */
document.addEventListener("copy", (e) => { /* Process event */ });
    
	
    
	
    The copy event is a kind of ClipboardEvent.
	This means it has the clipboardData property.
    
	
    Note: there are also events for cutting and pasting.
